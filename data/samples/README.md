# Public Domain Sample Manuscripts

These sample manuscripts are provided for testing, demonstration, and evaluation of Qifrey.

All texts in this directory are in the **Public Domain** in the United States and were sourced from [Project Gutenberg](https://www.gutenberg.org/):

1. **`jekyll_and_hyde_sample.txt`**:
   - Excerpt from *The Strange Case of Dr. Jekyll and Mr. Hyde* by Robert Louis Stevenson.
   - Project Gutenberg eBook #43.
2. **`alice_in_wonderland_sample.txt`**:
   - Excerpt from *Alice's Adventures in Wonderland* by Lewis Carroll.
   - Project Gutenberg eBook #11.
3. **`scandal_in_bohemia_sample.txt`**:
   - Excerpt from *The Adventures of Sherlock Holmes: A Scandal in Bohemia* by Arthur Conan Doyle.
   - Project Gutenberg eBook #1661.
